## 🧠 Sobre o projeto

O **Culturama** é uma aplicação front-end que simula uma plataforma de conteúdos culturais, como vídeos, músicas e eventos.

Este projeto foi desenvolvido com o objetivo de praticar:

- Estruturação semântica com HTML5
- Layouts responsivos
- Uso avançado de CSS
- Organização de estilos
- Boas práticas de UI


## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid


## 📱 Responsividade

O projeto foi desenvolvido com abordagem **mobile-first**, garantindo boa usabilidade em:

- 📱 Mobile
- 📲 Tablet
- 💻 Desktop


## 🎯 Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados conceitos importantes como:

- Criação de layouts complexos com **Grid**
- Alinhamento e distribuição com **Flexbox**
- Estruturação de componentes reutilizáveis
- Adaptação de layout para diferentes telas
